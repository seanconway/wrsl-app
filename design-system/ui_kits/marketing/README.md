# Marketing kit

refremote.com — a single landing page aimed at event organisers evaluating the system.
Dark throughout except one paper section, because the product itself is a dark matside screen.

**Files**

- `Site.jsx` — `Nav`, `Hero`, `Steps`, `Surfaces`, `CTA`, `Footer`, `Wordmark`, `Photo`
- `index.html` — the full page

**Rules this page encodes**

- Copy leads with the operational fact, not an adjective: "One referee, no table judge, no
  scoreboard operator." Numbers are specific (`30 m`, `9 h`, `<40 ms`).
- The wordmark is plain type — **no logo exists and none was drawn**. `Wordmark` is the
  reusable lockup.
- Photography is the only imagery. `Photo` is a placeholder block with the bottom protection
  scrim already applied — **drop real mat photography in and the scrim keeps type legible.**
  There is no illustration system, so no illustration appears.
- The lime CTA band is the one place lime is used as a large field, and it is the last thing
  on the page.
- Product surfaces are shown by rendering the actual components (`ScoreTile`, `MatchClock`,
  `MatTile`, `DeviceStatus`), not by screenshotting them.
